⚡ Agentes ConectaFramework

PHP 8.2+ MVC

5 agentes especializados para seu framework. Clique em um agente, copie o prompt e cole em qualquer conversa com Claude.

Como usar: Abra uma nova conversa com Claude → Cole o prompt do agente como primeira mensagem → A partir daí, Claude vai responder como especialista no ConectaFramework seguindo todos os padrões do seu AGENT.md.

📁 Onde salvar os arquivos gerados

🗄️ Repository → src/Repository/NomeRepository.php
⚡ Service → src/Service/NomeService.php
⚡ Controller → src/Controllers/NomeController.php
🎨 Views → views/modulo/index.php, create.php, edit.php
🏗️ Rotas → adicionar em public/index.php
🐛 Logs → verificar em storage/logs/
